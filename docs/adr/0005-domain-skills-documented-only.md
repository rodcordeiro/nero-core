# Skills de domínio documentadas, nunca incluídas

A skill operacional do motor é `$nero`. Skills acopladas a produto/libs (auth, webhooks, components, etc.) saem do canônico. O Kit documenta como implementar e usar um Domain Skill no fork/local do usuário, sem publicar o conteúdo dessas skills no Nero.

**Considered Options**: slots de domínio no monorepo canônico; manter components como exemplo.
